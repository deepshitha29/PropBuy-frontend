# PropBuy — Frontend

This is the static frontend for **PropBuy** (property acquisition and resale platform).

## Deployment (Vercel)
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other**.
3. Build & Output Settings: Leave as default.
4. Click **Deploy**.

## Backend Connection
The frontend connects to the PropBuy backend on Render:
- Default API Base: `https://propbuy-backend-8ztf.onrender.com`
- You can also test or update the backend URL directly on the live website by clicking **⚙ API Settings** in the footer.
